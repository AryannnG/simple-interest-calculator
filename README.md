
# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Description
This project calculates simple interest using the principal amount, annual rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## How to Run
1. Clone the repository.
2. Open a terminal in the project directory.
3. Run `bash simple-interest.sh`.
4. Enter the principal, rate, and time period.
